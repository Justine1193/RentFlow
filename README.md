# RentFlow

Full-stack application built with React, TypeScript, Tailwind CSS, Express, and Prisma (PostgreSQL).

## Project Structure

```
├── client/     # Frontend (React 19, TypeScript, Vite, Tailwind CSS v4)
├── server/     # Backend (Express, TypeScript, Prisma ORM, JWT, Bcrypt)
└── package.json
```

## Getting Started

### 1. Install Dependencies
```powershell
npm run install:all
```

### 2. Start Frontend
```powershell
npm run client:dev
```

### 3. Start Backend
```powershell
npm run server:dev
```
